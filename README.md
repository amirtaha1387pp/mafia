# مافیا کینگ (Mafia King)

وب‌اپلیکیشن **PWA** با PHP/SQLite/JS/CSS برای بازی مافیا با تم فضایی.

## امکانات پیاده‌سازی‌شده
- ثبت‌نام، ورود اجباری و تایید کد چندرقمی (OTP) قبل از ورود به اپ.
- نقش‌های کاربری: بازیکن، ادمین، ادمین ارشد، مالک (RBAC).
- لابی دوستانه/امتیازی تا ۳۰ نفر، سناریوهای متعدد، مدیریت سناریو/نقش سفارشی.
- چت زنده در لابی + سیگنالینگ WebRTC برای مکالمه صوتی زنده.
- پنل ادمین برای: افزایش جم/سکه، تغییر نقش، افزودن آواتار، مشاهده گزارش تخلفات.
- فروشگاه: خرید آواتار/آیتم با سکه و جم، ثبت رسید خرید جم.
- PWA: manifest + service worker (قابل بسته‌بندی برای Android/iOS/Desktop با ابزارهای Wrapping مانند Capacitor/Tauri/PWA Builder).
- چندزبانه (fa/ar/en/zh در UI پروفایل).

## اجرا
```bash
php -S 0.0.0.0:8000
```
سپس: `http://localhost:8000`

## نکته تولید (Production)
- OTP فعلی در محیط توسعه داخل Session نمایش داده می‌شود؛ برای تولید، سرویس پیامک واقعی وصل کنید.
- برای مقیاس بالا، SQLite را با MySQL/PostgreSQL و signaling را با WebSocket server جایگزین کنید.
- برای بازی‌های بزرگ صوتی، SFU (مثل mediasoup/Janus) توصیه می‌شود.
